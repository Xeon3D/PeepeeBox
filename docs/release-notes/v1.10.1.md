* I.G.O. 5 IT (CZ033) boots. It is the first I.G.O. 5 build, "Version 2005" without the B, and it reads the dongle the way I.G.O. 2 and 3 do; it was being sent the 2005B record and stopped at "wrong dongle version".
* The emulation speed is in the status bar now, where the refresh rate was, instead of at the end of the toolbar.
* The network card is off by default — no cabinet had one. For an image with the Ethernet option, fit it under **Tools > Network…** by choosing the Realtek RTL8139C+ as NIC 1. Configurations saved by 1.9 to 1.10 start without it as well, so switch it back on there if you use it.
* The 1999 cabinets' dongle has been identified: it is a Marx CRYPTO-BOX, either the 560/Net or the Versa.
