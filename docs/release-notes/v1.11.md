* I.G.O. 3 (2003) boots. Menu, games and photo games, with the photographs decrypting — before, it stopped at "dongle error" before the menu.
* I.G.O. 3's dongle emulation is **beta**: its games check the dongle against a table of answers recorded from a real one, and PeepeeBox replays that table off the disk image instead of computing them.
* I.G.O. 5 IT (CZ033) boots. It is the first I.G.O. 5 build, "Version 2005" without the B, and it reads the dongle the way I.G.O. 2 and 3 do; it was being sent the 2005B record and stopped at "wrong dongle version".
* Automatic updates: PeepeeBox looks at its GitHub releases page when it starts (and hourly, daily, weekly or monthly while running — or never) and, when a newer release is out, says which one and asks. Update now installs it over the folder while the cabinet keeps running and offers a restart; **Preferences > Updates** has the settings, a Check now, and the Update button for later. The prompt can show the new release's notes before you take it.
* This is the first release that can update itself, so 1.9.2 and earlier still need a manual download; from here on they do not.
* The network card is off by default — no cabinet had one. For an image with the Ethernet option, fit it under **Tools > Network…** by choosing the Realtek RTL8139C+ as NIC 1. Configurations saved by 1.9 and 1.10 start without it as well, so switch it back on there if you use it.
* Photo Play 2.0 images are identified by name, so the hard disk image manager lists them and the window title says which one it is.
* `ppfix` repairs more 2.0 images, and grows one that is too small.
* The emulation speed is in the status bar now, where the refresh rate was, instead of at the end of the toolbar.
* The touchscreen has one interrupt setting, the one in its Options.
* The 1999 cabinets' dongle has been identified: it is a Marx CRYPTO-BOX, either the 560/Net or the Versa.
* The About box credits: x86 hardware emulation & gui design by the 86box team; all photoplay-related emulation by Xeon3D / Team HUEG PP.
