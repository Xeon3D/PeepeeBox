* Quick taps on the touchscreen are no longer lost. A very short tap now always reaches the game as a touch and a release. The controller also used to overwrite a byte before the game had read it; when that byte was the release, the finger stayed "down", and the next touch became a drag from the old spot.
* The MicroTouch controller now does everything in 3M's reference guide: the Binary, Zone and Raw formats, the Point, Down/Up and Polled modes, the calibration commands, and the settings a game stores in the controller (parameters, sensitivity, filter, line speed), which are kept between runs. Tablet reports set status bit 3, which 3M's later touch drivers need.
