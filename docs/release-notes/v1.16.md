* PeepeeBox now runs on Android. Each release includes `PeepeeBox-android-arm64.apk`, next to the Windows, Linux and macOS downloads. It needs a 64-bit ARM phone or tablet with Android 9 or later. The app has a Machine Manager that lists the images in its folder, identifies each one (release, territory, NSB), and runs it with the right dongle. Images come in with Import. The cabinet screen has Credit (a long press picks any of the ten coins and notes), Setup, Fullscreen, and More, which holds the network card, the modem, Pause, Reset and About. See [android/README.md](https://github.com/Xeon3D/PeepeeBox/blob/main/android/README.md).
* The ES1688 sound card no longer goes silent on ARM builds. Its filter-clock calculation converted a negative value straight to a byte, which C leaves undefined: x86 builds happened to get the right answer, but the Android build got zero, and the card's output filter silenced everything it played. The macOS build for Apple silicon is compiled the same way and may have been affected too.
