* Automatic updates: PeepeeBox looks at its GitHub releases page when it starts (and hourly, daily, weekly or monthly while running — or never) and, when a newer release is out, says which one and asks. Update now installs it over the folder while the cabinet keeps running and offers a restart; the new **Preferences > Updates** page has the settings, a Check now, and the Update button for later.
* This is the first release that can update itself, so 1.9.2 and earlier still need a manual download; from here on they do not.
